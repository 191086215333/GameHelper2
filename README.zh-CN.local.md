# GameHelper2 中文界面与新增插件

按原项目 README 构建完整 `GameOverlay.sln`，从构建输出目录运行 `Launcher.exe`。按 **F12 → 常规与快捷键 → 语言 → 简体中文** 切换；繁体中文也在同一菜单。中文显示需要包含相应字形的字体及完整中文字集。

## 汉化与设置界面

当前主程序和 11 个插件的 1,669 条英文基准界面资源均已提供简体、繁体版本。其中包含 Atlas2 的 67 条祭祀词缀及短标签。未知名称保持原文，游戏内部 ID、权重和已保存的过滤条件保持不变；本项目并未提供全游戏所有装备随机词缀的翻译数据库。

设置按「刷图与收益、地图与探索、角色与战斗、拾取与物品」分类，支持插件中文名、原名和描述搜索。未启用插件保留入口；未分类的社区插件放入「其他插件」。背景图片为原创生成素材，来源和提示词见 `GameHelper/Assets/README.md`。

繁中物品、地图与预兆名称参考 PoE2DB 的英繁对照；新增简中内容从繁中资源经 OpenCC 转换后校对操作用语。运行软件不依赖 Python 或 OpenCC。游戏直接提供的物品名称仍由客户端语言决定。

## 刷图通货统计

F12 → 刷图与收益 → 刷图通货统计。支持区域计时、背包新增通货统计、横向收益条、会话历史和 CSV 导出。估值采用 LootValue 当前联盟和来源的有效缓存，无价格显示 `—`，部分未估值显示 `*`。

统计的是有效采样期间背包通货总数的正向变化，不是地面掉落总数或扣除成本后的净利润。切图、失焦、读取中断和大型面板操作后重新建立基准，不补计中断期间的变化。资料保存在 `Plugins/LootTracker/config/`。详情见 `Plugins/LootTracker/README.md`。

## 传送门诊断（恢复暂停）

F12 → 刷图与收益 → 传送门交互恢复。2026-10-05 进图崩溃后，恢复功能已暂停并锁定为只读诊断；旧配置也不能开启写入。扫描增加时间与读取上限。只读诊断从客户端调试代码识别四项状态的位置；恢复行为仍未验证，不能宣称死亡后恢复传送门已可用。详见 `Plugins/PortalAccess/README.zh-CN.md`。
