# 传送门交互恢复

F12 → 刷图与收益 → 传送门交互恢复。

插件初次使用默认仅检查，不修改游戏。进入有传送门的区域后，查看列表是否识别到门，并显示“校验通过”；开启“恢复传送门交互”才会尝试修改。简体、繁体、英文均已提供。

它把仍存在的 Portal 实体的 Targetable 组件中“可选中”“可高亮”两个字节由 0 改为 1。只采用 GameHelper2 自身的命名字段偏移，未引入参考软件的授权模块或混淆地址。它不会创建已经被移除的门，不能保证服务器允许再次进入地图，也没有改变地图次数的服务器逻辑。

默认每 1000 毫秒检查一次，切区后等待 1500 毫秒。配置保存在本插件目录的 `config/settings.json`。默认观察模式只申请读取权限；开启恢复时才为本插件单独申请写入权限，框架原来的内存句柄保持只读。

关闭恢复开关、停用插件或正常退出软件时，尝试还原本插件在当前区域内修改且仍匹配原实体的字段。切区或游戏重启后丢弃旧地址；如果地址失效、实体被替换或字段已经变成其他值，会跳过还原。强制结束程序或崩溃无法保证执行退出清理。

本插件使用的是当前源码的组件布局（0x51 / 0x52），结构校验不是对当前游戏版本兼容性的保证。字段可能在更新后改变。若列表显示跳过或报错，不要自行猜测地址；点击“导出传送门诊断”，检查 `config/portal-diagnostics.json`。诊断只包含区域标识、门实体及字段状态等本功能信息。修改计数是成功写入的字段数，不代表成功进入地图的次数。

验证状态：已完成全解决方案编译、三语言资源检查，以及模拟和本测试进程内存的 20 项读写/还原测试。尚未完成实际游戏中死亡后重新进入地图的验证。若死亡后 GameHelper2 已移除该实体，本插件不会扫描任意旧地址或凭空恢复它。
