# 傳送門交互恢復

F12 → 刷圖與收益 → 傳送門交互恢復。

初次使用預設僅檢查。進入有傳送門的區域，確認列表識別到門並顯示「通過」後，開啟「恢復傳送門交互」才會嘗試修改。支援繁體、簡體及英文。

本插件嘗試恢復客戶端內仍存在的 Portal 實體的可選取、可高亮狀態。它不會建立已移除的門，能否再次進入地圖仍取決於伺服器。切區後會清除舊地址；關閉開關、停用或正常退出時，會對仍符合原始實體的欄位嘗試還原。強制結束程式或當機無法保證清理。

預設每 1000 毫秒檢查一次，切區後等待 1500 毫秒。設定儲存於本插件的 `config/settings.json`。檢查模式唯讀，開啟恢復才單獨申請寫入權限。

若無法識別傳送門、校驗略過或修改失敗，可按「匯出傳送門診斷」，檔案位於 `config/portal-diagnostics.json`。成功修改欄位數不等於成功進圖次數。

目前已通過編譯、三語資源檢查與 20 項本地讀寫／還原測試，尚未實測目前遊戲版本死亡後再次進圖的效果。既有偏移及結構校驗不能保證新版遊戲相容；實體已被移除時不會掃描任意舊地址。
