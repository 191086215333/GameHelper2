# PortalAccess（恢復功能暫停）

2026-10-05 進圖發生存取違規崩潰後，此版本暫停交互恢復。
F12 → 刷圖與收益 → 傳送門交互恢復，目前僅提供**唯讀診斷**。
舊設定中的 `RestoreInteraction: true` 會自動關閉，恢復開關無法開啟；
插件不會取得遊戲寫入權限，停用或退出時也不進行還原寫入。
底層寫入介面僅允許離線測試操作測試程式自己的記憶體。

遊戲轉儲記錄了無效指標 `0x10100`，與原先兩個單位元組寫入的組合一致，
目前客戶端的唯讀分析已找到崩潰呼叫鏈中的 Targetable 解構函式，
確認其 0x50 處是動態陣列；舊 0x51/0x52 偏移落在陣列指標內部。
這些證據強烈指向佈局錯誤，轉儲仍未包含實際被損壞的堆積物件。
不得根據框架繼承的舊偏移繼續寫入。

診斷從目前客戶端的除錯函式文字標籤識別「可選取」「對玩家隱藏」「任務條件」
和「物品條件」四項狀態。函式與標籤必須位於遊戲主模組內，欄位不能重疊，
數值必須是布林值，讀取前後必須確認實體與元件身分一致。
未識別的結構不顯示狀態。此檢查僅驗證唯讀解讀，不能證明門的模型或伺服器進圖次數已恢復；寫入繼續暫停。

活動、休眠實體與保留記錄共用每次 15 毫秒、4,000 次讀取上限；
每張實體表最多遍歷 2,000 個節點，最多保留 128 個傳送門身分。
切區或程序變化時停止採樣。達到上限會標記採樣不完整，大型地圖可能漏讀部分門。
設定與診斷位於 `config/`，活動採樣每 10 秒自動儲存。

[離線測試](../../Tests/README.md) 僅使用模擬記憶體與測試程序自己的記憶體，不連接遊戲。
